# OOPs (Object-Oriented Programming)

The four pillars + supporting concepts, one package each:

| Package | Concept |
|---------|---------|
| `classesobjects` | classes, objects, `this` keyword |
| `constructors` | default/parameterized constructors, constructor overloading, constructor chaining |
| `inheritance` | extends, super, types of inheritance |
| `polymorphism` | method overloading vs overriding, dynamic dispatch |
| `encapsulation` | private fields + getters/setters, data hiding |
| `abstraction` | abstract classes vs interfaces |
| `interfaces` | multiple inheritance via interfaces, default/static methods |
| `statickeyword` | static variables, methods, blocks, initialization order |
